# SlowedLab

SlowedLab is a real-time audio player for slowing down music and applying
audio effects such as reverb and time-stretching.

## Features

- Real-time audio playback
- Slow and reverb effects
- Adjustable audio controls
- Playlist and local-file support
- User-friendly desktop experience
- Self-hosted/open-source project structure

## Project Status

The project is under active development. The source code and current
development setup are available in the lowercase `main` branch.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/talalhassankhan18/SlowedLab.git
cd SlowedLab
```

Install the dependencies using the package manager documented in the
application source, then start the frontend and backend services.

Before running the project, review the environment-variable example files
and configure only local development values. Never commit API keys,
passwords, or deployment credentials.

## Repository Structure

- `frontend/` — user interface
- `backend/` — server-side functionality
- `enalid/` — packaged application assets and previous release files
